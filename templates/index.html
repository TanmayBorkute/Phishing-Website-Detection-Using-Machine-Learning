About Project

 

  
Objective
Build and compare ML classifiers that detect phishing websites from URL and website features, and expose the best one through a web application.

   
Problem Statement
Phishing sites imitate trusted brands to steal credentials. Blacklists lag behind new sites, so feature-based ML detection is needed to flag unseen threats.

  
Dataset
UCI Phishing Websites (ID 327): 30 features encoded as −1 (phishing-like), 0 (suspicious), 1 (legitimate-like); target Result.

   
Technologies
Python · Flask · Pandas · NumPy · Scikit-learn · Joblib · Chart.js · HTML/CSS/JS
